# Fonctionnalité: Lister les clients API

> L'administration retrouve tous les clients API, du plus récent au plus
> ancien.

## Règle: Les clients API se listent du plus récent au plus ancien

### Scénario: Le dernier client créé ouvre la liste

* Étant donné un client API "Tableau de bord"
* Et un client API "Observatoire"
* Quand l'administration liste les clients API
* Alors "Observatoire" précède "Tableau de bord" dans la liste
