# Fonctionnalité: Mesurer l'usage des tags

> L'administration suit l'adoption des tags : combien de médiateurs en ont créé
> qui servent dans une activité, combien d'activités en portent, et
> quels tags reviennent le plus.

## Règle: Un tag compte dès qu'il sert dans une activité

### Scénario: Le créateur d'un tag utilisé compte parmi les créateurs

* Étant donné la mesure de l'usage des tags
* Et un médiateur qui a utilisé son tag dans une activité
* Quand l'administration mesure à nouveau l'usage des tags
* Alors les créateurs de tags utilisés sont 1 de plus
* Et les activités portant un tag sont 1 de plus
